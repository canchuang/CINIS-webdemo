# 缩略导航手势更新

适用 CINIS、镇岳、MOVA，复用同一份 JS / CSS。

- 点击缩略图：平滑跳到章节，选中框滑向目标；侧栏持续展开，移除定时收起。
- 点选或长按定位后，在菜单以外再次滚轮滚动、拖动或触摸滑动超过 10px 才收起。外部单击及程序定位不会触发收起。
- 普通滑动：仅滚动缩略图列表，选中框在侧栏内保持原位，正文不变化；释放后支持惯性浏览。
- 长按 360ms：进入定位状态，选中框跟手移动。命中章节立即同步正文与 aria-current，不等待松手。列表边缘自动滚动，松手后吸附到章节并更新地址锚点，侧栏保持展开。
- 超过 8px 的提前移动取消长按候选，按普通滑动处理。菜单重新展开后恢复跟随当前章节；Esc 和菜单按钮仍可关闭。
- 保留真实页面缩略图、菜单形变、中英文标签及减少动态效果回退，无新依赖。

## 本地浏览器验收

- 桌面 CINIS：原生 550ms 长按，pointerup 捕获阶段已检测到 is-dragging，当前章节 #ov、正文 scrollY=1330，证明定位发生于松手前。
- 桌面普通拖动使列表 scrollTop 从 0 到 170，正文仍为 #ov / 1330；稳定后选中框保持 y=547，滚动浏览不移动框。
- 375px 独立 iframe 视口 CINIS：默认收起，展开后长按 #ov；松手前已同步 #ov，正文 scrollY=1015。普通拖动后列表 scrollTop=160，正文及框 y=491 均保持不变。
- 移动端菜单外再次拖动后 aria-expanded=false。桌面外部点击不关闭，外部滚动后关闭。
- 本次使用桌面浏览器原生鼠标手势及移动尺寸独立视口检查，未进行实体手机触摸测试。
