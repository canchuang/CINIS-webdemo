# 缩略导航 · 实际页面预览与连续动效

## 改动
- 用对应章节的真实 DOM 内容生成缩小预览：标题、正文、图表和界面布局一起缩放。每章只保留首个预览视口所需内容，不再使用单张素材或文字占位卡。
- 所有副本均 inert / aria-hidden，移除 ID、脚本和 WebGL 画布；不创建 iframe 或新增截图服务。
- 一个共享选中框，四边各超出缩略图 4px。点击时采用 420ms 位移动画；页面滚动时跟随当前章节，避免跳动切换独立边框。
- Pointer Events 支持长按 360ms 后拖动选中框，拖动时关闭缓动以跟手，靠近列表边缘自动滚动，移动中实时定位对应章节。普通滑动只浏览缩略列表。键盘点击和 Esc 收起保留。
- 右下角小菜单与长侧栏共享外壳，按 bottom-right 锚点展开 / 收回；350ms 尺寸与圆角变化，内容延后淡入并解除轻微模糊，支持快速反向切换。
- 动效参考：Transitions.dev library 的 Dropdown menu morph。原输入 transition.dev 无法访问，经查证对应站为 https://transitions.dev/；实际打开示例并观察开合与计算样式。实现为项目独立代码，无新依赖。
- 手机点击章节后保持展开，菜单范围外再次滑动后收起。减少动态效果偏好使用即时状态。

## 验收
- CINIS 桌面实际点击 flow：共享框数量 1；框 88×78，缩略图 80×70；无副本 ID；无横向溢出。
- 浏览器原生鼠标拖动 flow → ia 及 ia → flow：当前位置与计数正确更新；Pointer Events 同时处理 touch 指针。
- 375px 独立视口中 MOVA：15 个实际章节预览，点击 pay 正确定位且无横向溢出。
- 展开 / 收起中测得中间高度，结束后由 44px 小菜单展开到桌面约 466px 高侧栏；手机侧栏 148×446px。
- 中英文切换后真实预览标题同步重建，移除所有重复 ID。
