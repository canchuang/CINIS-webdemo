# 作品详情页缩略导航

- 范围：CINIS、镇岳、MOVA 三个详情页；portfolio-redesign 分支。
- 右下角缩略目录，真实项目图配合文字章节缩略卡；当前章节边框与章内阅读位置框随滚动更新。
- 点击跳到真实章节，保留现有目录锚点；封面和 CINIS 的失败分支、原型章节补充独立锚点。
- 桌面大于等于 1280 默认展开，并为正文预留右侧空间；移动和平板默认收起，选择后收起。
- 手动浏览缩略列表时暂停跟随四秒，避免与用户抢滚动；Esc 关闭并将焦点返回按钮。
- 视觉按最新反馈精简：移除可见面板标题、缩略图下方说明与底部长标题，仅保留缩略图、细线框和位置计数；名称通过悬停提示与无障碍标签提供。
- 键盘链接、aria-current、aria-expanded、减少动态偏好、移动端安全边距与中英文切换支持。
- 缩略导航不克隆全文，不建立 iframe，不额外引入依赖；缩略图片复用已有资源。

## 实测
- 桌面三个页面点击跳转到 flow / structure / seat，当前项正确跟随。
- 375px 手机 CINIS：默认关闭，展开可见列表；跳转后关闭，目标顶部约 140px，未被导航遮挡。
- 三页 × 375 / 768 / 1280 / 1440，共十二组宽度检查：无横向溢出，移动默认关闭 / 桌面默认展开符合设计。
- 中英文目录、Esc 关闭测试通过。
- 目录目标 / 图片存在性、HTML ID 唯一性与 JS 语法检查通过。
- 含封面共 CINIS 14 项、镇岳 12 项、MOVA 15 项；编号代表章节位置，并非额外拆分页面。

仅更新 GitHub portfolio-redesign 和对应 Netlify 分支预览，不合并主分支。
