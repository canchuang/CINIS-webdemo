- 右下角缩略目录已升级为真实章节内容缩放预览；共享选中框连续移动，详见 CASE-MINIMAP-MOTION.md。
- 点击跳到真实章节，保留现有目录锚点；封面和 CINIS 的失败分支、原型章节补充独立锚点。

- 缩略导航仅复制每章首个预览视口所需内容，不复制整篇全文；无 iframe、额外依赖或截图服务。
