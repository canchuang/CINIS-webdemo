## 持久化与迁移

`cinis:state:v3` 保存目标、逐日任务计划、完成事件、专注会话、模式、提醒、阶段记录。所有任务完成入口写同一账本；同一任务只记录一次。快速记录不计有效专注时间；启动专注后不能用快速记录绕过计时。任务完成后不提供“反勾撤销奖励”。

首次打开时，将旧 `cinis:goals` 和 `cinis:reminder` 的有效配置迁移；旧 `demo-state`、`growth`、`focus-session` 原值保留于 legacy，旧 key 不删除。有明确保存的旧 XP 和称号继续显示；没有日期的旧完成态不冒充今日任务，未知来源的历史数值不编造成任务记录。旧版本进行中的会话只备份，不直接发放奖励。数据与隐私页可导出包含 legacy 的完整 JSON。

无旧目标数据时，将原示例任务名称初始化为可编辑目标；所有完成态从未完成开始，成长统计从真实记录开始。清空记录后维持空白状态，不重新灌入示例。

目标新建立即生成今天的任务；编辑、删除从明天生效，已生成的当天任务与历史快照不回写。休息日不生成任务，不增加阶段分母。今日日期、等级、经验不再读取固定示例值。

## 本地日期与跨夜专注

日期使用本机 `getFullYear/getMonth/getDate`，不用 UTC 截取日期。日历推进使用本地正午，避免夏令时按 24 小时累加造成日期偏差。页面在前台每秒、窗口恢复、可见性变化时核对状态；后台暂停计时不会导致倒计时变慢，因为剩余时间从 deadline 计算。

本地零点创建独立任务 ID 和新一天计划；历史、XP、称号保留。跨夜专注归属开始当天，结束后确认一次完成，不自动把旧任务记入新一天。阶段最后一天开始的未处理专注会暂缓该阶段结算；确认或退出后再结算。暂停超时会中断，不发奖励。

## 统一规则

|规则|旅者|骑士|深渊|
|---|---|---|---|
|阶段|7 天|7 天|5 天|
|完成率门槛|无|85%|100%|
|未达门槛时暂存魂火损失|0%|30%|100%|
|单次专注可暂停次数|不限|1|0|
|单次专注暂停最长时间|不限|10 分钟|不适用|

`domain/engine.ts` 的 RULES 是文案、计时器和阶段结算的共同来源。骑士/深渊未达标只影响暂存魂火，已获得 XP 和称号不撤回。阶段结算按确定的任务快照算一次；有效专注只统计完整计时后确认完成的任务。没有计划任务的空阶段不制造一次“成功”。

上述“专注暂停”与旧设计文档中的数天“阶段休整”分开。此版本没有增加多日阶段休整、裂痕补做、追回损失等机制，也移除了相关未实现的功能入口/固定损失数字，避免宣称按钮已实现这些规则。

成长页、历史、角色档案、成就墙和“我的”读取同一账本，三种身份共享经验与称号。深渊成长场景仍使用现有角色素材，不声称已有独立场景插画。

## 提醒边界

保存每日时间与星期配置，尝试申请浏览器通知权限；网页保持打开且支持 Notification 时，所选分钟内最多发送一次。关闭网页、移动端后台挂起后的可靠定时推送需要服务端推送或原生通知，本版本不承诺。旧场景偏好仍保留在数据中，未把未实现的补做/裂痕提醒展示为可用开关。

## 验证

- `pnpm test`：状态、三模式奖惩、重复结算、跨日/跨阶段、夏令时、配置校验。
- `pnpm test:ui`：组件操作、存储重新载入、提醒和三模式专注界面。
- `pnpm test:e2e`：真实浏览器端到端用例，由 CI 执行；本执行环境的 Chromium 进程因 socket 权限限制无法启动，本地未宣称端到端通过。
- `pnpm build`：TypeScript 与生产打包。

此为单机浏览器存储。跨标签页会刷新其他页最新数据，但同时写入的严格事务保证、多设备同步与后台推送不在本次实现中。
