## 1. 问题与调整（前后对比）
- **调整前**：`.about-grid` 为 `.8fr / 1.2fr` 两栏，**全部正文（简介→设计理念→专业方向→技能→精选项目）都塞在右栏**；左栏只有一张较矮的「概览」卡（sticky）→ 其下方左侧**整列长期空置**，页面重心偏右。
- **调整后**：
  1. 顶部一行保留 **概览卡（240–300px）+ 简介（1fr）** 的双栏；
  2. 其下改为 **整行「左标题 / 右内容」的章节节奏**（设计理念、专业方向、技能与方法、精选项目），每节占满整宽，左侧承载章节标题、右侧承载内容，**不再出现空置整列**；
  3. 专业方向在桌面为 **三列**，与下方内容宽度匹配；
  4. 1440px 页面高度由约 **2848 → 2370px**，重心居中、留白均匀。
- **内容零改动**：身份、学校年级、项目顺序（CINIS→便携式储能→MOVA）、文案均沿用 Phase 20。
